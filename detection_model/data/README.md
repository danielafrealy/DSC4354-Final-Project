# Data

## Consent
The detection side uses only **public benchmark images**, so no consent forms are
needed for detection. Enrollment photos of real people are handled by the
verification side and require signed consent.

## Benchmark samples
- **Fake faces:** "140k Real and Fake Faces" dataset (Kaggle); fakes generated by
  StyleGAN. Extra fakes from thispersondoesnotexist.com.
- **Real faces:** real images from the same Kaggle dataset (from FFHQ).

Put images in:
- `data/benchmark/real/`
- `data/benchmark/fake/`

Images are not committed to GitHub (see `.gitignore`).
